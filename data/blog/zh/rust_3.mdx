### 前言
写完 hello world ，这篇算是正式进入了 **Rust** 的世界了，让我们来了解一下 **Rust** 的基础概念，看他是如何在无 **GC** 的前提下保持如此优秀的内存管理的。

### Rust 的特殊概念（路线图）

在深入学习之前，先来认识一下 Rust 中几个区别于其他语言的核心概念，后续的文章会逐一展开详细介绍，这里先混个脸熟：

- **所有权（Ownership）**：Rust 的灵魂机制，每个值都有且只有一个所有者，所有者离开作用域时值会被自动释放，这就是 Rust 无需 GC 的秘密
- **借用（Borrowing）**：不想转移所有权？可以把值"借"出去，分为不可变借用 `&T` 和可变借用 `&mut T`，编译器会确保同一时刻不会出现冲突
- **生命周期（Lifetime）**：编译器用来追踪引用有效期的机制，确保你不会拿到一个已经被释放的值的引用，听起来复杂，用多了就自然了
- **宏编程（Macro）**：我们已经见过的 `println!` 就是一个宏，Rust 的宏系统非常强大，可以在编译期生成代码，远比 C 语言的宏安全
- **模式匹配（Pattern Matching）**：类似 `switch` 但强大得多，配合 `match` 和 `enum` 使用，写过函数式语言的读者应该会很亲切

不必现在就理解它们，带着印象往下走就好。

### 一个简单的例子

万里之路，行于脚下，先让我们从一个例子入手

#### ./src/main.rs
```rust

// Rust 程序入口函数，跟其它语言一样，都是 main，该函数目前无返回值
fn main() {
    // 使用let来声明变量，进行绑定，a是不可变的
    // 此处没有指定a的类型，编译器会默认根据a的值为a推断类型：i32，有符号32位整数
    // 语句的末尾必须以分号结尾
    let a = 10;
    // 主动指定b的类型为i32
    let b: i32 = 20;
    // 这里有两点值得注意：
    // 1. 可以在数值中带上类型:30i32表示数值是30，类型是i32
    // 2. c是可变的，mut是mutable的缩写
    let mut c = 30i32;
    // 还能在数值和类型中间添加一个下划线，让可读性更好
    let d = 30_i32;
    // 跟其它语言一样，可以使用一个函数的返回值来作为另一个函数的参数
    let e = add(add(a, b), add(c, d));

    // println!是宏调用，看起来像是函数但是它返回的是宏定义的代码块
    // 该函数将指定的格式化字符串输出到标准输出中(控制台)
    // {}是占位符，在具体执行过程中，会把e的值代入进来
    println!("( a + b ) + ( c + d ) = {}", e);
}

// 定义一个函数，输入两个i32类型的32位有符号整数，返回它们的和
fn add(i: i32, j: i32) -> i32 {
    // 返回相加值，这里可以省略return
    i + j
}

```

### 几个要点

#### ⚠️ 分号的含义
Rust 中 `;` 是有实际含义的，`i + j` 没有添加 `;` 则表达为 返回 `i + j` 否则 `add` 函数 则返回一个 单元类型 `()`。这一点对于写惯了 `JavaScript` 的同学来说需要特别注意，在 JS 中分号更多是格式规范，但在 Rust 中它决定了这行代码是**语句**还是**表达式**。

#### 字符串与字符
上篇中介绍过，Rust 中字符串使用 `""` 来进行表达，`''` 则表达字符(char)，这和 `JavaScript` 中单双引号混用完全不同。

#### 格式化占位符
在 Rust 中，格式化占位符使用 `{}` 来进行表达，其他语言可能是 `%s`, `%d`, `%p`，由于 **println!** 宏会自动推断出类型，因此无需手动指定。如果想输出调试信息，还可以用 `{:?}` 来打印实现了 `Debug` trait 的类型，后续我们会经常用到。
