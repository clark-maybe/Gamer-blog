### 前言
上篇聊完了变量绑定与解构，这篇我们来看看 Rust 中有哪些基础类型。对于写惯了 `JavaScript` 的同学来说，`typeof` 返回的那几个类型已经刻在 DNA 里了，但 Rust 作为一门系统级语言，对类型的划分要精细得多，毕竟要精确控制内存嘛。

Rust 的基础类型大致分为两类：**标量类型**（Scalar）和 **复合类型**（Compound）。

<DividerSmall />

### 标量类型

标量类型代表一个单一的值，Rust 有四种基本的标量类型。

#### 整数类型

这可能是 Rust 类型系统中最让前端同学震惊的部分了，在 JS 中一个 `number` 走天下，Rust 直接给你掰开了：

| 长度 | 有符号 | 无符号 |
|------|--------|--------|
| 8-bit | i8 | u8 |
| 16-bit | i16 | u16 |
| 32-bit | i32 | u32 |
| 64-bit | i64 | u64 |
| 128-bit | i128 | u128 |
| 视架构而定 | isize | usize |

`i` 代表有符号（可以为负），`u` 代表无符号（只能为正或零），后面的数字表示占用的位数。

```rust

let age: u8 = 25;        // 年龄不会是负数，u8 足矣（0~255）
let temperature: i16 = -20; // 温度可以为负
let big_number: i64 = 9_000_000_000; // 下划线分隔，增强可读性

```

其中 `isize` 和 `usize` 比较特殊，它们的大小取决于运行平台——在 64 位系统上就是 64 位，32 位系统上就是 32 位。主要用于集合的索引，比如数组下标。

如果不确定用哪个，**Rust 默认推断整数为 `i32`**，大多数情况下性能也是最优的。

#### 浮点类型

浮点数只有两种：`f32` 和 `f64`，默认推断为 `f64`。

```rust

let x = 2.0;      // f64，默认
let y: f32 = 3.0;  // f32，需要显式指定

```

和 `JavaScript` 一样，Rust 的浮点数遵循 IEEE 754 标准，所以 `0.1 + 0.2` 同样不等于 `0.3` -,-，这个锅不是哪门语言的，是浮点数标准本身的。

#### 布尔类型

```rust

let t = true;
let f: bool = false;

```

没什么意外的，和其他语言一样，占用 1 个字节。值得一提的是，Rust 不会像 JS 那样做隐式类型转换，`if 1 {}` 在 Rust 中会直接报错，必须是 `if true {}`，不存在所谓的 truthy / falsy 值。

#### 字符类型

```rust

let c = 'z';
let emoji = '😄';
let chinese = '中';

```

前面的文章提过，Rust 中 `''` 表示字符，`""` 表示字符串，二者是完全不同的类型。Rust 的 `char` 类型占 4 个字节，表示的是一个 Unicode 标量值，所以 emoji 和中文都没问题。

<DividerSmall />

### 复合类型

复合类型可以将多个值组合在一起，Rust 有两种原生的复合类型。

#### 元组（Tuple）

元组可以将不同类型的值组合在一起，长度固定，一旦声明后不能增减：

```rust

let tup: (i32, f64, u8) = (500, 6.4, 1);

// 用模式匹配解构
let (x, y, z) = tup;
println!("y = {}", y); // 6.4

// 也可以用索引访问（从0开始）
let first = tup.0;  // 500
let second = tup.1;  // 6.4

```

元组用 `.0` `.1` `.2` 来按索引访问，这个语法第一次看到可能会觉得奇怪，习惯就好-,-

还记得上篇提到的单元类型 `()` 吗？它其实就是一个空元组，在 Rust 中表示"没有值"，类似于其他语言的 `void`。当函数没有显式返回值时，默认返回的就是 `()`。

#### 数组（Array）

Rust 中的数组与 `JavaScript` 的数组差别很大：**长度固定，元素类型必须相同**。

```rust

let arr = [1, 2, 3, 4, 5];

// 显式标注类型和长度
let arr: [i32; 5] = [1, 2, 3, 4, 5];

// 快速初始化：创建一个包含 5 个 0 的数组
let zeros = [0; 5]; // [0, 0, 0, 0, 0]

// 访问元素
let first = arr[0];
let second = arr[1];

```

如果你需要一个长度可变的"数组"，那应该使用 `Vec<T>`（动态数组），这个后续会详细介绍。

Rust 数组有一个很棒的特性——**越界检查**。在 C/C++ 中访问越界的数组下标是未定义行为（可能读到垃圾数据），但 Rust 会在运行时直接 panic（崩溃退出），避免你读到不该读的内存：

```rust

let arr = [1, 2, 3];
let index = 99;
let element = arr[index]; // 运行时 panic：index out of bounds

```

这就是 Rust 内存安全理念的一个缩影——宁可崩溃也不允许非法内存访问。

### 类型转换

Rust 不做隐式类型转换，这点和 JS 的画风完全相反。在 JS 中 `"5" - 1` 会得到 `4`，但在 Rust 中，不同类型之间的运算必须显式转换：

```rust

let a: i32 = 10;
let b: i64 = 20;

// 这样不行 ❌
// let sum = a + b;

// 必须显式转换 ✅
let sum = a as i64 + b;
println!("sum = {}", sum); // 30

```

`as` 关键字用于基础类型之间的转换，虽然写起来麻烦一点，但它让每一处类型转换都清晰可见，不会出现 JS 中那种 `[] + {} === "[object Object]"` 的魔法行为-,-

<DividerSmall />

### 小结

Rust 的类型系统初看会觉得繁琐——整数就分了十几种，连加法都要对齐类型。但换个角度想，这些"麻烦"都发生在编译期，一旦编译通过，运行时就不会出现类型相关的 bug。这也是 Rust 的哲学：**把问题暴露在开发阶段，而不是让用户去发现**。
